# Security Policy

If you discover a security issue, please do not open a public issue right away.

Instead, report it privately to the maintainer first so there is time to investigate and prepare a fix. If no dedicated private channel is available yet, use the repository owner's preferred contact method and include:

- A short description of the issue
- Steps to reproduce
- Impact assessment, if known
- Any suggested mitigation

I will try to acknowledge reports promptly and keep you updated on the resolution process.
